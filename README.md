# Swift URL Shortener [Swift URL](https://swift-url.onrender.com/home.html)

[swift.xo.je]{swift.xo.je}

A simple URL shortener made using only HTML, TailwindCSS, and JavaScript.

## Features
- Shortens long URLs
- Copy shortened URL to clipboard
- Basic UI with responsive design

## How It Works
1. User enters a long URL into the input field.
2. Clicking the "Lets go" button generates a short alias.
3. The short URL is displayed, allowing the user to copy it.
4. When the short URL is visited, JavaScript redirects to the original URL.

## Usage
1. Clone or download this repository.
2. Open `index.html` in a browser.
3. Enter a URL and click "Lets go".
4. Copy and share the generated short URL.

## Files
- `index.html` - Main structure of the application.
- `redirect.js` and `func.js` - JavaScript logic for URL shortening and redirection.
